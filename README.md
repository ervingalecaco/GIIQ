# GIIQ — Gestión Integral del Inventario de Química

Repositorio del proyecto de Examen de Grado: sistema de inventario de reactivos y
cristalería del laboratorio de química.

| Carpeta | Qué contiene |
|---|---|
| [`GIIQ/`](GIIQ/) | **La aplicación completa**: base de datos, API (.NET), interfaz web (React), proyecto Android y manual de instalación. |
| [`documentacion/`](documentacion/) | Documentos de análisis y contexto del proyecto. No se necesitan para instalar. |

## Instalar en otra computadora

Solo hace falta la carpeta **`GIIQ/`**: copiarla (o descargar el repositorio) y seguir
su guía, [`GIIQ/README.md`](GIIQ/README.md). El manual detallado en PDF está en
[`GIIQ/docs/manual/GIIQ_Manual_Instalacion.pdf`](GIIQ/docs/manual/GIIQ_Manual_Instalacion.pdf).
